# Fiber Network API

API desarrollada con FastAPI para la gestión de nodos de redes de fibra óptica.

## Tecnologías

- Python
- FastAPI
- Pydantic

## Funcionalidades

- Crear nodos
- Listar nodos
- Consultar nodo por ID
- Actualizar nodos
- Eliminar nodos

## Ejecutar

```bash
uvicorn main:app --reload
```
